PROGRAM 04

TITLE
Implement Recursive and Iterative Versions of Tower of Hanoi and Analyse the Recurrence Relation, Number of Moves, Recursion Tree and Execution Time

PROBLEM STATEMENT
Implement the Tower of Hanoi problem using recursive and iterative approaches. Analyse the recurrence relation, number of moves, recursion tree and execution time.

OBJECTIVE
1. To implement Tower of Hanoi using recursion.
2. To understand its recursive structure.
3. To derive the recurrence relation.
4. To determine the number of moves.
5. To analyse recursion depth and execution behaviour.

ALGORITHM USED
Recursive Tower of Hanoi

REASON FOR SELECTING THIS ALGORITHM
Tower of Hanoi has a naturally recursive structure. To move n disks, n-1 disks are moved to the auxiliary peg, the largest disk is moved to the target peg, and n-1 disks are moved to the target peg.

The recursive method represents this structure directly and gives a short, clear implementation.

ALGORITHM
1. If n = 1, move the disk from source to target.
2. Move n-1 disks from source to auxiliary recursively.
3. Move the largest disk from source to target.
4. Move n-1 disks from auxiliary to target recursively.
5. Continue until all disks are moved.

RECURRENCE RELATION
T(n) = 2T(n-1) + 1

NUMBER OF MOVES
2^n - 1
