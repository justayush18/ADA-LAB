PROGRAM 05 - COMPLEXITY ANALYSIS

PRIMARY ALGORITHM
Modified Merge Sort

TIME COMPLEXITY
Best Case: O(n log n)
Average Case: O(n log n)
Worst Case: O(n log n)

Merge Sort has O(log n) levels and O(n) merging work at each level.

SPACE COMPLEXITY
O(n)

Additional lists are created during merging.

BRUTE-FORCE METHOD

Time Complexity:
Best Case: O(n²)
Average Case: O(n²)
Worst Case: O(n²)

Space Complexity:
O(1)

The brute-force method checks every possible pair.

COMPARISON
Modified Merge Sort: O(n log n)
Brute Force: O(n²)

Therefore, Modified Merge Sort is more efficient for large input sizes.

EXECUTION-TIME NOTE
The measured time depends on Python runtime conditions, hardware, and system load. The main theoretical comparison is between O(n log n) and O(n²).
