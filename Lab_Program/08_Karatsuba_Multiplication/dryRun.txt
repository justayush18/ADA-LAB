PROGRAM 08 - DRY RUN

INPUT
x = 1234
y = 5678

Split:
1234 = 12 × 100 + 34
5678 = 56 × 100 + 78

a = 12, b = 34, c = 56, d = 78

ac = 12 × 56 = 672
bd = 34 × 78 = 2652

Middle term:
(12 + 34)(56 + 78) - 672 - 2652
= 46 × 134 - 672 - 2652
= 2830

Combine:
672 × 10000 + 2830 × 100 + 2652
= 7006652

Both methods produce the same product.
